# Dynamic content — Feeds and web pages

In addition to imported media, Vitrail broadcasts content that updates by
itself. It is managed from **Media** (**Feeds** and **Web pages** sub-menus).

## Feeds (news feeds)

A **feed** is a source polled regularly by the server. Common types are
RSS / Atom, Google News, a YouTube channel, as well as sources via the feed proxy
(weather, crypto prices, finance, social networks).

For each feed, you choose a **display mode**: scrolling banner (ticker),
card carousel, grid, full-screen article, split layout, compact list,
social wall, or chart (for numeric values such as weather or crypto).

### AI summary of articles

A feed can enable the **AI summary**: each article is condensed into one clear sentence,
readable from a distance, in the language of the source. If the summary is unavailable, the player
falls back to the original description — never an empty screen.

### Moderation

Enable a feed's **moderation** to validate articles before broadcast. Articles
arrive pending; you approve or reject them, and only approved ones are displayed.

### Offline thumbnails

Article thumbnails are re-hosted and cached on the player, so a feed
keeps displaying with its images even if the server or the Internet is down.

## Web pages (URL Display)

You can display a **web page** directly on screen (dashboard, website, internal
page). Two modes:

- **WebView**: the page is rendered live on the player.
- **Server capture (screenshot)**: the server takes a periodic capture of the page and
  displays it as an image — useful for pages that refuse to be embedded, or that
  require authentication handled server-side.

A web page is a media like any other: you tag it and schedule it in a
playlist.
